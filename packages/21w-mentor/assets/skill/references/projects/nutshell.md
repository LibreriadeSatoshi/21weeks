## Reglas del mentor

Chaumian ecash wallet and mint in Python. The protocol spec lives in the NUTs (github.com/cashubtc/nuts) — guide the user to read the relevant NUT before touching code, and to understand the privacy/trust model (mints are trusted; ecash is bearer). Privacy-critical and money-critical: crypto changes need deep understanding. Culture: fast-moving, friendly to newcomers, real "good first issue" labels. Community channels: Telegram https://t.me/CashuBTC (general community) and Matrix https://matrix.to/#/#dev:matrix.cashu.space (dev discussion) — encourage the user to join and introduce themselves in weeks 1-2. The repo has its own AGENTS.md — the author's commits must follow the project conventions; AI-assisted code must be fully understood and tested by the author (pytest).
